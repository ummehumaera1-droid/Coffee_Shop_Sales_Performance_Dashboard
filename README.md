# Coffee Shop Sales  Analysis

## Project Overview
Brew Metrics is a comprehensive data visualization project designed to analyze the sales performance of a coffee shop chain across multiple cities. The dashboard provides actionable insights into revenue trends, product popularity, and regional performance, helping stakeholders make data-driven decisions to optimize operations and increase profitability.

## Dataset used
- <a href="https://github.com/ummehumaera1-droid/Coffee_Shop_Sales_Performance_Dashboard/blob/main/Coffee_Shop_Sales.xlsx">Dataset</a>

## Project Objectives
The goal of this project is to turn raw sales data into actionable business insights:
- Track Growth: Monitor MoM changes in transactions, revenue, and profit.
- Analyze Trends: Identify sales seasonality and weekly transaction patterns.
- Product Performance: Evaluate top-performing categories (e.g., Coffee, Snacks).
- Geographic Insights: Compare revenue across New York, Chicago, and Los Angeles.
- Profitability: Analyze the correlation between total revenue and net profit.

## Questions (KPIs)
1. What are the key performance indicators (KPIs)
- total transactions, quantity sold, total revenue, and total profit?
2. How are transactions distributed across different product categories (e.g.,
- coffee, food, snacks)?
3. What are the weekly transaction trends?
- Which days of the week show the highest and lowest number of sales?
4. What is the year-over-year revenue comparison?
- Use pie charts or other visuals to show growth.
5. Which product’s categories contribute most to total revenue?
6. How do monthly sales vary across the year?
- Show trends using line or column charts.
7. Which cities are generating the highest revenue?
- Create a clear, city-wise revenue breakdown.
8. How does revenue compare to profit across categories or time periods?
- Use comparative visuals to display this relationship.
